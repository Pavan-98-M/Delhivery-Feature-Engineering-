# 🚚 Delhivery Logistics Case Study – Data Analysis

This project is a **business case study** on Delhivery, one of India’s largest logistics companies.  
The goal was to analyze **freight, orders, and customer behavior** to identify operational challenges, optimize costs, and improve service efficiency.

---

## 📊 Project Overview
The analysis focuses on:
- Studying **freight cost patterns** across locations  
- Identifying **delivery inefficiencies and delays**  
- Understanding **customer demand trends**  
- Evaluating **state-level logistics performance**  
- Providing **data-driven recommendations** for growth  

---

## 🛠️ Tools & Skills
- **SQL** → Data extraction and analysis  
- **Excel** → Data cleaning and summary statistics  
- **Statistics** → Descriptive analysis & probability insights  
- **Business Case Study Approach**  

---

## 🔑 Key Insights
- 🚚 Certain states had **higher freight costs despite low order volume**, indicating inefficiencies.  
- ⏰ Delivery times varied significantly; **on-time delivery was inconsistent** across regions.  
- 📈 Seasonal spikes in orders suggested the need for **resource reallocation during peak demand**.  
- 💰 Optimizing freight costs could directly improve **profit margins and customer satisfaction**.
